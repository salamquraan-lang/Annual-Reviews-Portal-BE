# Annual Reviews Portal: Backend

REST API for the Annual Reviews Portal, an employee performance review platform.

## Technology

| Area | Choice |
| --- | --- |
| Language | Python 3.12+ |
| Web framework | FastAPI |
| Database | MySQL 8 |
| Data access | SQLAlchemy 2 |
| Migrations | Alembic |
| Dependencies | Poetry |

## Prerequisites

- Python 3.12 or newer
- [Poetry](https://python-poetry.org/docs/#installation) 2.x
- A running MySQL 8 server

## Getting started

1. Create the database.

   ```sql
   CREATE DATABASE employee_review CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

2. Install the dependencies. Poetry creates the virtual environment in `.venv/`.

   ```bash
   poetry config virtualenvs.in-project true
   poetry install
   ```

3. Create the environment file and fill in the values (see [Configuration](#configuration)).

   ```bash
   cp .env.example .env
   ```

   On Windows, use `copy` instead of `cp`.

4. Apply the database migrations.

   ```bash
   poetry run alembic upgrade head
   ```

5. Start the server.

   ```bash
   poetry run python -m app
   ```

The API listens on `http://localhost:4000`. A health check is available at `GET /api/health`.

## Configuration

Settings are read from environment variables or from the `.env` file.

| Variable | Required | Default | Description |
| --- | --- | --- | --- |
| `DATABASE_URL` | Yes | | MySQL connection string, for example `mysql+pymysql://user:password@localhost:3306/employee_review` |
| `JWT_ACCESS_SECRET` | Yes | | Secret for signing access tokens. At least 32 characters. Generate one with `openssl rand -hex 32` |
| `NODE_ENV` | No | `development` | `development`, `test` or `production` |
| `PORT` | No | `4000` | Port the server listens on |
| `APP_URL` | No | `http://localhost:5173` | Frontend URL. Used for CORS and for links in emails |
| `TRUST_PROXY` | No | `false` | Set to `true` only behind a reverse proxy that sets `X-Forwarded-For` |
| `ACCESS_TOKEN_TTL_MINUTES` | No | `15` | Access token lifetime |
| `REFRESH_TOKEN_TTL_DAYS` | No | `7` | Refresh token lifetime |
| `VERIFY_EMAIL_TTL_HOURS` | No | `24` | Email verification link lifetime |
| `RESET_PASSWORD_TTL_MINUTES` | No | `30` | Password reset link lifetime |
| `RATE_LIMIT_WINDOW_MINUTES` | No | `15` | Rate limit window |
| `RATE_LIMIT_MAX` | No | `300` | Requests per window for each client |
| `AUTH_RATE_LIMIT_MAX` | No | `20` | Failed authentication requests per window for each client |
| `SMTP_HOST` | No | empty | Mail server. When empty, emails are written to `tmp/mail/` instead of being sent |
| `SMTP_PORT` | No | `587` | Mail server port |
| `SMTP_USER` | No | empty | Mail server user |
| `SMTP_PASS` | No | empty | Mail server password |
| `MAIL_FROM` | No | `Employee Review <no-reply@example.test>` | Sender address |

## Project structure

```
alembic/        Database migrations
app/
  routers/      HTTP endpoints
  services/     Business logic
  models.py     SQLAlchemy models
  schemas.py    Request and response schemas
  security.py   Password hashing and tokens
  config.py     Settings
pyproject.toml  Project metadata and dependencies
poetry.lock     Exact dependency versions
```

## Database migrations

```bash
poetry run alembic upgrade head                      # apply all migrations
poetry run alembic revision --autogenerate -m "msg"  # create a migration from model changes
poetry run alembic downgrade -1                      # undo the last migration
```

Always review an autogenerated migration before committing it.

## Dependencies

Add a package with `poetry add <name>`. This updates both `pyproject.toml` and `poetry.lock`. Commit both files.
